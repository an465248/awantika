# AnMusic Downloader (Android App)

A modern, high-speed Android application for downloading 4K/HD video and high-fidelity MP3 audio from 1000+ social and media streaming platforms (YouTube, Instagram, TikTok, Twitter/X, Facebook, Vimeo, SoundCloud, Reddit, Twitch, and more).

## Key Features

- **Universal Media Extraction**: Direct high-speed video and audio resolution via Cobalt and fallback streaming backends.
- **Multiple Formats & Qualities**:
  - **Video (MP4)**: 1080p Full HD, 720p HD, 360p SD, and source quality.
  - **Audio (MP3)**: 320 kbps High Quality, 192 kbps, and 128 kbps.
- **Real-Time Progress & Speed**: Live transfer rate meter (MB/s), downloaded size, and shimmer progress indicators.
- **Media Library & Local Persistence**: Built-in Room database storing downloaded files, thumbnails, platform tags, duration, and timestamps.
- **In-App Media Player**: AndroidX Media3 (ExoPlayer) with full controls, time-seeking, and animated audio waveforms.
- **System Integration**: Native Android Share intent receiver (`ACTION_SEND`) to download links directly when sharing from YouTube, TikTok, or browsers.
- **Customizable Server**: Support for custom backend endpoints and local download directory management.
